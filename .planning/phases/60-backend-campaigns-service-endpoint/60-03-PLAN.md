## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Laravel service → OpenCTI GraphQL | All user-controlled values flow through typed GraphQL variables (`$first`, `$after`, `$search`, `$orderBy`, `$orderMode`). Nowdoc heredoc disables PHP interpolation. |
| Service → Cache | Cache key derived server-side from `func_get_args()`, never from raw user input — cache-poisoning safe. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-60-05 | Tampering | GraphQL query construction | mitigate | Nowdoc syntax `<<<'GRAPHQL' ... GRAPHQL` (single-quoted) disables PHP interpolation; all values via `$variables` array. Typed variables (`Int!`, `String`, `CampaignsOrdering`) validate server-side at OpenCTI. |
| T-60-06 | Privilege Escalation | SC4 field bleed | mitigate | Normalizer whitelists Campaign fields ONLY. Positive SC4 test asserts heredoc contains `CampaignsOrdering`; negative SC4 test asserts absence of `primary_motivation`, `resource_level`, `goals`, `motivation` in response. |
| T-60-07 | Tampering (server-side) | Cache key namespace collision with `threat_actors:` | mitigate | Hardcoded prefix `'threat_campaigns:'` (Pitfall 4 in RESEARCH.md); test explicitly computes the expected key and asserts `Cache::has()` on it. |
| T-60-08 | DoS | Client passes huge `$first` value | mitigate | Controller hardcodes `$first = 24` (D-04). Service default is 24 — no user-controlled override surface in Phase 60. |
